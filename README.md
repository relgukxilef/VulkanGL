# VulkanGL
Vulkan wrapper for OpenGL, allowing you to use the Vulkan API on platforms that only support OpenGL.

For examples of how this can be used look at my other repositories: 
* [hello-emscripten](https://github.com/relgukxilef/hello-emscripten) renders a world read from a gltf file and allows WASD-navigation through it.
* [immediate-mode-vulkan](https://github.com/relgukxilef/immediate-mode-vulkan/tree/wip/racing-game/demo) on the wip branch has a racing game demo.
